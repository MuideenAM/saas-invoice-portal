A full-stack, multi-tenant invoicing and billing web application built for small businesses and freelancers. Enables seamless client management, dynamic PDF invoice generation, and secure online payment tracking.



\## 📌 Features

\- \*\*Multi-Tenant Dashboard:\*\* Role-based access control for admins, team members, and clients.

\- \*\*Dynamic PDF Generation:\*\* Instant generation and auto-emailing of customizable PDF invoices.

\- \*\*Payment Gateway Integration:\*\* Integrated payment links supporting credit cards and online transfers.

\- \*\*Analytics \& Reporting:\*\* Real-time metrics on paid vs. pending invoices, revenue charts, and client ledger histories.



\## 🛠️ Tech Stack

\- \*\*Backend:\*\* PHP (Laravel) / RESTful API

\- \*\*Frontend:\*\* React, Tailwind CSS

\- \*\*Database:\*\* PostgreSQL

\- \*\*Tools:\*\* Docker, Azure Cloud Hosting
